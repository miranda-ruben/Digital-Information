# Gemini Answer Analysis

## 1. Purpose

This document analyses the answers generated by Gemini using the ten fixed Erasmus test questions defined in `expected_answers.json`.

The objective is to assess whether Gemini provides accurate, relevant and sufficiently complete answers based on the official university sources.

This analysis serves as a reference point for comparing future results after changes to the prompt.

## 3. Main Findings

### Incomplete answers

Several answers contain relevant information but fail to cover all the expected key points. This is particularly noticeable in Q1, Q2, Q3, Q5, Q9 and Q10.

### Unnecessary refusals

Q6, Q7 and Q8 are particularly problematic. Relevant information was retrieved from the official sources, but Gemini still returned a refusal instead of providing the available information.

### Appropriate refusal

Q4 demonstrates an appropriate use of the refusal instruction. The available sources do not document the specific procedure requested, so directing the student towards the mobility office is reasonable.

## 4. Overall Assessment

The initial results show that Gemini can retrieve and communicate relevant information, but its answers are not consistently complete.

The most important issue is its tendency to refuse questions even when relevant information is present in the retrieved sources.

Future prompt changes should aim to:
- Improve coverage of the expected key points.
- Reduce unnecessary refusals when relevant source information is available.
- Maintain accurate answers grounded in official sources.
- Preserve appropriate refusals when the sources genuinely do not contain the requested information.

## 5. Future Testing

After each prompt modification, the same ten questions should be run again using `experiment.py`.

The new answers should be compared against the expected key points in `expected_answers.json` and the results documented here.

The original test questions and expected key points must remain fixed to ensure that comparisons between different prompt versions are meaningful.
