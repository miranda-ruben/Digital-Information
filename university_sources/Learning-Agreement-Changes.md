# Learning Agreement - Student Mobility for Studies - Changes to learning agreement

## What the form contains
- Student: last name(s), first name(s), study programme, Winter/Summer and year.
- Sending institution: Universite du Luxembourg, Luxembourg. Receiving institution: name and country (to be filled in).
- Table A2 - "During the mobility / Exceptional changes to Table A": for each course, the component code (if any), the component title at the receiving institution (as in the course catalogue), a tick for Kept component / Deleted component / Added component, the reason for change, and the number of ECTS credits (with a total).
- Table C2 - "Exceptional changes to Table C (VIRTUAL COMPONENT if applicable)": component code, component title or description, a short description of the virtual component (obligatory field), reason for change, number of ECTS credits to be awarded, automatic recognition (Yes), with a total.
- Signatures and dates: the student, the receiving institution, and the sending institution.

## Reasons for exceptional changes to study programme abroad (choose the item number)
Reasons for deleting a component:
1. Previously selected educational component is not available at the Receiving Institution
2. Component is in a different language than previously specified in the course catalogue
3. Timetable conflict
4. Other (please specify)

Reasons for adding a component:
5. Substituting a deleted component
6. Extending the mobility period
7. Adding a virtual component
8. Other (please specify)

## Definitions printed on the form
- Mobility type: Semester(s): a study period abroad lasting at least one academic term/trimester or 2 months to 12 months.
- An "educational component" is a self-contained and formal structured learning experience that features learning outcomes, credits and forms of assessment. Examples: a course, module, seminar, laboratory work, practical work, preparation/research for a thesis, mobility window or free electives.
- Course catalogue: detailed, user-friendly and up-to-date information on the institution's learning environment that should be available to students before the mobility period and throughout their studies.
- Automatic recognition: All credits gained abroad, as agreed in the Learning Agreement and confirmed by the Transcript of Records, will be transferred without delay and counted towards the student's degree without any additional work or assessment. This is signalled by the "Yes" check box. If "No" is selected, a clear justification is needed and an indication of what other type of formal recognition will be applied (e.g. diploma supplement or Europass Mobility Document).
- Responsible person at the Sending Institution: an academic who has the authority to approve the Learning Agreement, to exceptionally amend it when needed, and to guarantee full recognition of the programme.
- Short description of a virtual component: an indication of whether it is an online course(s), embedded in a course selected at the receiving institution, embedded in a blended intensive programme and/or another online activity, with titles or a short description.

## Key facts
- Steps: Fill in Table A2 (and Table C2 for virtual components) with the kept, deleted or added courses and a reason code; sign; have the receiving institution sign; then send it to the faculty mobility contact for validation by the sending institution.
- Form needed: "Changes to learning agreement" form (this Word form). Used when the host university does not use the Online Learning Agreement (OLA).
- Office responsible: Faculty mobility contact (FDEF: Stephanie Anderson, stephanie.anderson@uni.lu; see the Erasmus checklist for FSTM and FHSE contacts).
- Deadline: Not published in this document. The checklist says to update the learning agreement within the month of arrival; host universities may set their own deadlines.
